# Definition of Done — Proje ve Faz

**Versiyon:** 1.0

---

## Story / task Done sayılır when

- [ ] Kod (ilgili fazda) merge edilebilir durumda  
- [ ] Unit/integration testler ilgili AC geçiyor  
- [ ] Türkçe copy [COPY_DECK](../design/COPY_DECK.md) ile uyumlu veya deck güncellendi  
- [ ] RBAC doğrulandı  
- [ ] Audit gereken path log yazıyor  
- [ ] Dokümantasyon API değiştiyse [API_REFERENCE](../technical/API_REFERENCE.md) güncel  
- [ ] staging smoke pass  
- [ ] Bilinen bug P0 yok
